## 3. 固定策略与允许控制

### 3.1 启动前

从同一完整初值出发，在含回流模型中使用常规措施 `(c0,q0)`，定位I首次由下方达到eta的时刻t1，保存完整启动状态。每组参数只生成一份经过核验的启动状态，由该组全部优化和参照控制共用。

不得用无回流的启动时刻或启动状态替代。未触发、触发状态S不高于Sc等退化情况须显式报告，不强行进入平台优化。

### 3.2 阈值控制期

要求I恒等于eta；以S、Sq为两个状态，以c为一个独立控制，通过

\[
q=1-\frac{\gamma N}{\beta cS},\qquad
\frac{c_0S_c}{S}\le c\le c_0
\]

消去q。这对应q0不高于q且q小于1的允许范围。动力学为

\[
\begin{aligned}
\dot S&=-\frac{c[\beta+(1-\beta)q]}{N}S\eta+\omega S_q,\\
\dot S_q&=\frac{(1-\beta)cq}{N}S\eta-\omega S_q.
\end{aligned}
\]

自由终时t2定义为S首次到达Sc的时刻；t1不高于t且t小于t2时必须有S大于Sc。允许S在Sc以上非单调变化，不额外约束其单调下降。

用归一化时间tau=(t-t1)/(t2-t1)上的lambda(tau)作为数值控制：

\[
c=\frac{c_0S_c}{S}+\lambda(\tau)
\left(c_0-\frac{c_0S_c}{S}\right),\qquad 0\le\lambda\le1.
\]

lambda=1对应仅隔离，lambda=0对应仅减少接触。lambda可以随时间自由变化；不强制相同S取相同控制，不把搜索限制为旧的c(S)或alpha族。

控制期时长作为优化变量。可利用现有有限退出论证中的F下界设置理论时长上界；若另加数值时长或尾段积分上限，必须检查上限是否起作用并记录，不能把撞到人为上限的结果当作最优解或不可行性证明。

### 3.3 退出后

在首次S=Sc时永久恢复 `(c0,q0)`；不瞬时释放Sq，不重新启动干预，不优化退出后的控制。Sq继续按omega回流。

本计划的主可行类要求从初始时刻起全过程I不超过eta，包括退出后的全部时间。六类主问题都使用这一要求，不能通过越过阈值换取较短时长或较低成本。

## 4. 三个目标及统一评价

### 4.1 最短控制期

\[
\min \Delta t,\qquad \Delta t=t_2-t_1.
\]

最短控制期不等于最早达到I=1；后者仅作辅助输出，不列为本轮第四个优化问题。

### 4.2 最少全过程累计新增感染

\[
\min C_\infty,\qquad
C_\infty=\int_0^\infty\frac{\beta c(t)S(t)I(t)}{N}\,dt.
\]

累计新增感染包括流入I和Iq的人数，不加初始感染者。启动前感染对同组各控制相同，仍计入最终报告。退出后按固定常规措施计算，不以首次向下I=1自动截断。

同时报告控制期累计新增感染，但不另行优化该指标，不把它与全过程目标混称。

### 4.3 最低干预成本

\[
\min J,\qquad
J=\int_{t_1}^{t_2}\left[
\left(\frac{c_0-c}{c_0}\right)^2+
2\left(\frac{q-q_0}{1-q_0}\right)^2
\right]dt.
\]

沿用当前二次强度成本，只计额外强度的控制期积分，不含隔离人天或货币支出。保持现有定义，不因优化结果不理想而改成本。

### 4.4 交叉评价

每一个最优候选都计算Delta t、J、控制期感染、退出时累计感染、C_infty、Sq(t2)、退出后峰值和阈值余量。三种最优候选必须在同一模型、同一可行类和相同全过程统计口径下比较。

数值缩放使用gamma*Delta t、C_infty/N、gamma*J/(wc+wq)；最终结果仍报告天和人。

## 5. 退出后阈值与无限时段的处理

### 5.1 将退出后的固定动力学纳入可行性

优化过程中从退出状态 `(S=Sc,I=eta,Sq=Sq(t2))` 继续积分常规动力学，或将这段作为无自由控制的被动配点阶段，约束I不超过eta。

不能只在平台节点上施加阈值约束，也不能只在优化结束后发现越界却仍保留该候选为主结果。若独立核验发现节点之间越界，加入对应时刻的约束或加密网格，重新求解。

主任务中不引入允许越阈值的替代策略。越界候选只保存为失败或诊断记录，不新增一整套无约束优化矩阵。

### 5.2 定位全部可能峰值

退出后的I为正时，常规控制下I的驻点由S=Sc确定。定位退出后所有S-Sc零点并判断极大、极小，同时使用连续插值及加密采样交叉检查，不能仅比较积分节点。

退出时自身是边界峰值候选；退出邻域须加密，不直接忽略靠近t2的事件。还须检查积分终点及各插值区间的极值，避免漏掉切触或非常接近的驻点。

### 5.3 无限时间的后续安全判据

记U=S+Sq。退出后继续采用常规控制，积分到某时刻T满足U(T)<Sc。由于U此后不增，S(t)不高于U(T)，I此后单调衰减。因此：

- 若退出至T之间已确认I不超过eta，且I(T)不超过eta，则T之后也不超过eta；
- 不要求退出瞬间U(t2)不高于Sc，因为S(t2)=Sc，这会强迫Sq(t2)=0并改变问题；
- 积分至人为上限仍未取得U<Sc判据的候选记为“尾段未完成/未判定”，不能直接记为不可行或安全。

### 5.4 全过程感染的尾部误差

在U(T)<Sc后，使用现有尾界

\[
0\le C_\infty-C(T)\le
B(T)=\frac{\beta c_0U(T)I(T)}{N\gamma[1-U(T)/S_c]}.
\]

初始验收预算：基准B不超过0.001人，西安B不超过0.1人。对接近的候选，尾界和积分误差还必须明显小于需要区分的感染差值，目标为不超过该差值的十分之一；否则继续收紧或报告无法区分。

优化过程的目标评估也须控制尾误差，不允许优化器利用不同尾段截断长度制造虚假改进。最终每个候选报告基于数值状态的感染估计区间及独立积分误差；尾界不包含浮点积分误差、控制离散化误差或最优值误差，不称为区间算术认证。

若两个感染估计区间重叠，或最优值变化仍受离散误差支配，不按名义末位数字宣布唯一排序。

## 6. 数值求解路线

### P0：无求解预检与问题冻结

核对输入身份、参数、模型、六类任务清单、求解器可用性、目标和约束定义。依赖检查不得触发优化。冻结配置及随机种子；任何依赖安装或方法更换须单独记录。

### P1：常规段和参照控制

每组参数生成一份含回流的启动状态。参照控制为仅隔离、仅减少接触、无回流最优状态反馈迁移；它们与新解共用启动状态和全过程评价标准。

复用现有14天轨迹的Delta t、J等记录核对新评估入口。现有C_term是首次I=1的截断值，不能直接冒充C_infty。实施时仅对本轮需要的参照进行统一尾段评价，不重跑其他停留时间或历史长时矩阵。

参照中违反全过程阈值者标记为不可行，不能作为主可行类的竞争最优解；其原始历史结果仍保留。

### P2：直接配点主求解

采用时间域直接配点及稀疏非线性规划，平台使用归一化时间与自由控制期时长。优先选用Radau类配点；具体软件及版本在执行预检确认后冻结。

平台控制区间数按20、40、80、160逐级加密；必要时仅在切换、退出或约束活跃位置继续局部加密。尾段独立自适应加密，不要求与平台使用同样节点数。

每类问题在粗网格至少使用8个起点：仅隔离、仅减少接触、迁移律、均匀混合、先隔离后接触、先接触后隔离，以及2个固定种子的平滑扰动起点。起点不必都可行，先进行明确记录的可行性恢复；恢复失败不能当作该问题无解。

在后续网格保留至少3条不同来源的可行候选继续求解。实际求解次数按记录统计，不能把六类问题称为仅运行六次优化。

### P3：第二种优化离散互证

对六类问题的最终候选，再用时间分段控制的shooting优化进行互证，至少从配点候选和一个不同形态起点启动。独立方法也必须满足同一终点、阈值和尾误差要求。

完整ODE回放只能核验给定控制，不能代替第二种优化方法。两种优化方法结果不一致时保留全部结果，检查离散化、局部极小、插值和约束；未解释前不发布唯一最优结论。

### P4：独立积分与精度复核

对全部最终候选及参照，独立重放完整五仓室方程。控制插值规则事先固定；按lambda(tau)及当前S重建c、q，不把I人工重置为eta，不修剪负仓室或人为修改控制使结果通过。

使用log(I/N)处理低感染人数阶段，避免用浮点下溢当作灭绝。独立积分采用与配点离散不同的自适应方法，并对最终候选用第二种积分方法或进一步收紧设置复核。

### P5：整理结果与停止

完成六类问题的交叉比较、控制曲线、收敛记录和未决项后停止。不自动向7天、30天或额外权重扩展，不自动修改论文或数字宏。

## 7. 核验标准

以下为执行前冻结的目标，达不到时加密或报告未通过，不放宽阈值、修改参数或覆盖失败历史。

| 类别 | 验收目标 |
|---|---|
| 优化状态 | 分别记录求解器success、原始终止码、KKT/最优性残差、迭代次数；success不等于科学验收 |
| 配点约束 | 缩放后的动态/等式最大残差不超过1e-8，目标1e-9；记录残差的明确定义 |
| 控制界限 | lambda在[0,1]内，数值越界残差不超过1e-9；核对重建c、q的允许范围 |
| 退出位置 | 独立回放的abs(S(t2)-Sc)/N不超过1e-9 |
| 首次退出 | 连续轨迹及事件检查确认此前未触及Sc；不能仅看配点节点 |
| 平台感染 | 独立完整ODE回放的max abs(I/eta-1)不超过1e-7 |
| 退出后阈值 | 检查全部峰值及尾部安全判据；超过eta的正偏差不得当作允许松弛 |
| 人数守恒与非负性 | 按N归一后的总人数残差目标1e-9；负仓室须排除超出积分误差的异常 |
| 感染恒等式 | 积分新增感染与U(0)-U(t)交叉核对；误差计入最终感染预算 |
| 时间、成本收敛 | 80到160区间的候选目标相对变化不超过1e-4；否则继续加密并记录 |
| 感染收敛 | 控制网格、尾界、独立积分三项误差分别报告；估计总不确定度不高于需要区分的候选差值的十分之一，否则记为无法区分 |
| 候选比较 | 最短时长解、最低成本解分别不能明显劣于同组其他可行候选和参照；感染按不确定区间比较 |

独立积分初始采用rtol=1e-10，S/N和Sq/N的atol不高于1e-12，log(I/N)的atol不高于1e-11；其他仓室及累计流量沿用现有分量尺度设计。最终收紧至rtol=1e-12，并相应收紧各分量atol及减小max_step，比较实际误差。平台和尾段按需要设置最大步长，不能只收紧rtol而保留过粗步长。

退出后阈值的数学条件始终是I<=eta。若max I/eta-1出现约1e-7量级的正偏差，列为数值边界情况，收紧后重新定位峰值；稳定的正超限须排除，精度仍不能分辨则报告“阈值可行性未判定”。仅能作数值可行性判断时明确说明精度，不宣称严格认证。

分别保存：`solver_success`、`dynamics_pass`、`threshold_status`、`tail_complete`、`mesh_pass`、`method_agreement`。不将它们合并为一个success字段；求解失败、动力学失败、确证数值越阈值和尾段未完成分别统计。

多起点、多网格及两种优化方法一致只能支持数值证据。没有有效全局下界或额外验证论证时，表述为“所采用离散化和起点下找到的最佳数值解”，不称已证明全局最优，也不从两条初值轨迹推出一般最优反馈。

- 任一任务未找到可行解，只报告“当前方法未找到”，不宣布数学不可行。
