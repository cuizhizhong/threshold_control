# 14天指数回流的数值优化研究

本目录对应作者2026-10-27明确启动的研究：基准/西安两组参数、平均停留14天、最短时长/最少全过程感染/最低二次强度成本，共六类优化问题。全过程要求I不超过eta，保持首次S=Sc退出，不释放、不重启。

仅本目录写入研究代码与证据，不修改论文、来源模块和历史科学结果；不推送。`plan_snapshot.md` 保留执行起点的计划，`results/manifest.json` 记录来源和环境，`results/protected_initial.json` 保留694个受保护文件的初始字节身份。

## 入口

- `preflight.py`：无科学求解的环境与来源核对。
- `collocation.py` / `run_collocation.py`：时间域Radau3配点、IPOPT，多起点、20/40/80/160区间。
- `shooting.py`：独立分段常控制、矩阵指数精确平台传播及SLSQP优化。
- `evaluate.py`：独立完整五仓室ODE，I不固定，事件核对、尾界和阈值核验。

使用 `E:/anaconda/envs/thesis/python.exe`。为保持来源只读，运行时设置 `PYTHONUTF8=1`、`PYTHONDONTWRITEBYTECODE=1`；设置 `OMP_NUM_THREADS=1` 避免并行线程过量。CasADi 3.8.2只安装在本目录 `_runtime/`，该目录不进入Git；其余科学环境版本见manifest。

CasADi的CVODES被动尾段取基准600天、西安4000天；优化内显式检查尾界和U<Sc，并在尾段输出网格施加阈值约束。最终以独立自适应ODE、所有峰值和解析尾界复核，不以固定尾段长度本身保证精度或安全。

## 证据边界

全部优化尝试保留；非线性规划success、约束残差、独立ODE可行性、网格收敛、方法互证分开记录。独立ODE回放不是第二次优化。全过程感染不在首次I=1处停止；基于数值状态的尾界不是区间算术认证。

感染目标只通过退出Sq影响固定尾段，存在早期控制影响很弱的数值平坦方向；若候选感染差小于不确定度，只报告无法区分，不按成本或时长较差的某个平坦方向解宣称唯一最优形态。

所有命令须显式指定求解任务，不在模块导入时自动运行优化。最终运行计数分别列优化调用、独立ODE、初猜ODE与优化内部尾段评价，不把六类任务写成仅六次求解。
