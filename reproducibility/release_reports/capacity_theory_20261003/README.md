## 数学边界复核

独立数学复核与主控复核均未发现剩余阻断项：

- `q_cap=q_max` 可行，启动时取上限，随后严格低于上限。
- `q_cap=q_0` 时，内部触发状态下仅隔离不可行；若联合条件成立，接触削减在退出前的整个正长度状态区间必要。
- `c_min=c_0` 时，两种能力判据一致，不声称可行域严格扩大。
- 必要接触削减区间来自既有 `eq:joint:bounds`；不引入新的记号或乘积取值区间。
- `prop:joint:terminal-allocation` 及其证明逐字不变：退出附近内部最优要求 `c_min<c_0`、`q_cap>q_0`；严格比较只针对整段可行的单控制。
