## 入口、兼容与复现边界

- 新增 `reproducibility/threshold_revision.py` 的 `stage`、`verify`、`tests`、`publish` 入口；本轮已运行，对已有目录、版本或回执拒绝覆盖。不要删除旧记录或指针绕过保护。
- `threshold_revision_text.py` 固定批准的完整稿件哈希及保护内容；第9节唯一批准过渡绑定父/目标版本及旧新整稿和段落哈希。默认冻结/激活仍拒绝第9节变化。
- 版本可选保存文献库及编译脚本，源码收集纳入两者；旧版本兼容。隔离编译按两份文档分别检查书目，旧无参考文献SI仍用两遍XeLaTeX。
- `paper_sync.py` 活动分支本身无需重写医疗模板，读取新的受控快照即可；没有运行冻结底稿生成入口或上一轮写死版本的医疗合并流程。
- 科学身份仍承接 `runs/20261005_sec7_v2_refinement/run_1`、`run_2`及原选择、双跑、发布、汇集清单；所有本轮记录明确 `scientific_calculation_reexecuted=false`。
