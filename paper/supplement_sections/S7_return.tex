\section{回流情景与数值核验}
\label{sec:sup:return}
本节给出正文第~\ref{sec:return}~节摘述的数值：指数回流情景的全部结果（表~\ref{tab:sup:return:base}、\ref{tab:sup:return:xian}）、无回流模型 $t\to\infty$ 的累计感染（表~\ref{tab:sup:return:cinf}），以及回流部分的收敛与容差检验。立即返回对照模型的端点小表见正文表~\ref{tab:return:endpoint}。

\emph{控制律。}仅隔离控制、仅减少接触与 $\alpha=0.5$ 的接触率状态函数取自正文第~\ref{sec:joint}~节。无回流最优律迁移（表中称迁移律）把 $\omega=0$ 时逐状态最小化得到的 $c_c^*(S)$ 原样用于 $\omega>0$：平台上遇到的任何 $S$，包括超过无回流启动状态 $S^*$ 的状态，都直接按 $\omega=0$ 的逐状态最小化计算，不插值、不外推，也不对 $\omega>0$ 重新优化，所以不称成本最优。立即返回对照模型的成本最优控制由正文式~\eqref{eq:return:cost} 逐状态最小化得到。逐状态最小化比较允许区间的两个端点与驻点方程在区间内的实根；全部控制不考虑能力约束，成本权重取默认值 $w_c=1,w_q=2$。

\emph{终止规则。}终止规则按模型分支确定。$\omega=0$ 与立即返回对照模型沿用正文的清零约定：退出后 $I$ 由上方到达 $1$ 的时刻为清零时间，$t\to\infty$ 的累计感染由首次积分解析补尾（正文定理~\ref{thm:s1:tend}的 $S_\infty$）。指数回流情景（$\omega>0$）以退出后 $I$ 首次降到 $1$ 的时刻截断，假设此时传播结束，这与清零时间的约定相同（正文第~\ref{sec:cost}~节，沿用文献\cite{Zhou2024SPCI}）；终止时累计感染即截断时刻的 $\Itcum$。它不是 $t\to\infty$ 的累计感染，可以低于正文命题~\ref{prop:return:final-size}的下界。

\emph{尾部误差标准。}同一轨迹若不截断而继续积分，$t\to\infty$ 的累计感染以尾部误差上界控制。退出后控制恒为 $(c_0,q_0)$，当 $U(T)<S_c$ 时 $S\le U\le U(T)$，故 $I(t)\le I(T)e^{-\gamma(1-U(T)/S_c)(t-T)}$，$T$ 之后的新增感染不超过
\[
B(T)=\frac{\beta c_0U(T)I(T)}{N\gamma[1-U(T)/S_c]} ;
\]
积分到 $B(T)\le10^{-6}U(0)$ 为止。这一不截断的结果只作诊断，不进表。

\emph{情景。}平均停留 $1/\omega=7,14,30,60,120,365$ d 中，60 d 以上是长停留诊断，不代表实际隔离制度。西安回流情景沿用正文表~\ref{tab:xian_initial_fit}的参数与初值，没有用病例数据重新校准含回流模型。越过阈值按退出后 $I/\eta-1$ 的内部极大值判定：大于 $10^{-8}$ 为越过，小于 $-10^{-8}$ 或没有内部极大为未越过，其余记为数值上未确定。

\subsection{收敛与容差}
\label{sec:sup:return:convergence}
\emph{立即返回对照模型。}逐状态最小化用等距网格 $N_x=2001,4001,8001$ 核对根法：在每组参数的退出附近对数加密的状态点上（含 $S=3S_c$ 与 $2\sqrt2\,S_c$），网格最小值减根法最小值的最大差（两组参数中的较大者）分别为 \rsIrNxGapTwoThousand、\rsIrNxGapFourThousand 与 \rsIrNxGapEightThousand（$S$ 坐标成本密度），约按 $N_x^{-2}$ 下降，没有状态违反“根法不高于网格”。$S$ 坐标求积用 $N_z$ 个节点的分段 Simpson，与自适应 quad 的 $\Delta t$、$J$ 的最大相对差在 $N_z=1001,2001,4001$ 时分别约为 \rsIrNzQuadRelCoarse、\rsIrNzQuadRelMid 与 \rsIrNzQuadRelMax；成本最优控制的切换位置不随 $N_z$ 变化。

\emph{迁移律的状态范围。}$\omega>0$ 时平台上的 $S$ 可以超过无回流的启动状态。基准参数下平台上的最大 $S/S_c$ 为 \rsBaseZPlateauMax（无回流的 $S^*/S_c$ 为 \rsBaseZStarNoreturn），西安参数下为 \rsXianZPlateauMax（\rsXianZStarNoreturn）。在这一范围内对 $\omega=0$ 的逐状态最小化同样用 $N_x=2001,4001,8001$ 核对，最大差分别为 \rsMigNxGapTwoThousand、\rsMigNxGapFourThousand 与 \rsMigNxGapEightThousand，与立即返回端同量级。

\emph{积分容差。}全部事件法轨迹共 \rsTolRuns 条，包括 \rsReturnRunsTotal 条指数回流轨迹（截断终点）、$\omega=0$ 与立即返回对照模型的各控制，以及释放用的轨迹。每条用三档积分设置各算一次：基准为相对容差 $10^{-11}$、最大步长 $1$ d；收紧为 $10^{-12}$、$0.5$ d；放宽为 $10^{-10}$、$2$ d；各分量绝对容差与相对容差同比缩放。收紧后启动时刻、退出时刻、控制时长、$J$、截断时刻、终止时累计感染、$t\to\infty$ 累计感染与退出后峰值的最大相对变化约为 \rsTolMaxRelChange，次峰 $I/\eta-1$ 的最大绝对变化约为 \rsTolMaxAbsEChange；越过判定与终止状态在三档设置下相同。总易感者恒等式（正文引理~\ref{lem:return:U}）的相对残差约为 \rsIdentityResidualMax。
