# 早期探索脚本（仅供追溯，已被 01、02 取代）

这些脚本使用旧的西安初值 I0=1.00663×10⁻³，数值与新初值的差别在报告精度以下，但不作为正式结果来源。

| 文件 | 内容 | 被什么取代 |
|---|---|---|
| `joint_cost_optimal.py` | 第一版平台类内逐状态全局最小与五仓室正向核对（权重、κ、能力上下界） | 01 的 `joint_numerics.py`（向量化、三阶段时间开环、与正式输出对账） |
| `joint_explore.py` | 更早的逐状态网格最小与局部极小计数 | 同上 |
| `lin_vs_quad.py` | 西安线性/二次成本对比、线性成本切换规则 s>s̄+r(1−s̄) 的核对 | 01 的 `results/linear_cost_xian.json`（新初值，TDINN 取 reference.json） |
| `xian_H.py` | 用辅助住院仓室 H（停留 L 天）估算床位占用峰值：H1 只由 I 流入，H2 由 I 与 I_q 共同流入 | 01、02 中的 (I+I_q)/η 峰值；该脚本的"占用倍数"依赖未标定的 L，未复核，不宜引用 |
