# 隔离易感者返回检验（探索性）

检验原模型"隔离易感者不返回 S"这一假设对阈值控制结论的影响。结论：不改模型，正文以注记说明（见总览）。

## 模型与控制

在原 SIQR 中加入 S_q → S，速率 λ：S' 增加 λS_q，S_q' 减少 λS_q。λ=0 即原模型。
控制采用跟踪 I=η 的状态反馈（I 达到 η 且常规控制不足以使 I 不增时，把 c(1−q) 调到维持 I=η 的值），
分配规则：仅隔离、仅减少接触、无回流模型下的最优分配 x*(s)。
`rule='oneshot'` 为原文规则（S 首次降到 S_c 即永久退出），`rule='feedback'` 允许再次启动。
固定步长 RK4，dt=0.01 d；dt=0.004 与反馈增益 k=0.5 的结果与默认设置一致到 4 位有效数字。
λ=0 时复现原文：西安仅隔离 85.07 d、J=40.77、累计 2.378×10⁶、清零 258.1 d。

本目录程序按新的西安 I0（reference.json 的 I0_abs=1.00659188867187e-3）重跑；`sq_return.py` 依赖同目录 `joint_cost_optimal.py`。

## 主要结果

西安（η=0.002N，权重 1:2；不返回 → λ=1/14）

| 策略 | 控制时长 (d) | 累计感染/N | 同时隔离峰值/N | 人均进入隔离次数 | 二次 J | (I+I_q) 峰值/η |
|---|---|---|---|---|---|---|
| 仅隔离 | 85.1 → 425.3 | 0.181 → 0.794 | 0.649 → 0.172 | 0.65 → 2.89 | 40.77 → 192.89 | 4.73 → 4.84 |
| 无回流最优分配 | 108.8 → 484.6 | 0.193 → 0.794 | 0.638 → 0.172 | 0.64 → 2.70 | 38.02 → 176.87 | 4.73 → 4.84 |
| 仅减少接触 | 308.8 → 857.2 | 0.293 → 0.794 | 0.537 → 0.022 | 0.54 → 1.46 | 109.37 → 299.49 | 1.46 → 1.46 |

不返回时 S_q 只进不出，"同时隔离峰值"等于最终累计值。

基准（N=763；不返回 → λ=1/14）：仅隔离 5.90 → 19.21 d，无回流最优分配 7.75 → 21.81 d，仅减少接触 36.26 → 38.47 d；累计感染 286/307/629 → 623/624/667。

- 保持的：时长排序（仅隔离 < 混合 < 仅减少接触）；S=S_c 退出后无反弹（oneshot 与 feedback 结果相同）；对 λ∈[1/21, 1/7] 不敏感。
- 改变的：西安时长约 5 倍；累计感染不再随分配变化（均约 79%N）；"以 S 为时钟"的一维化不再成立。
- 混合分配仍可优于仅隔离（alloc_under_return.json）：基准下用 r=1 推出的分配 J=2.770 < 仅隔离 2.827；西安下用 r=2 推出的分配 176.9 < 192.9。但无回流最优分配在返回模型中不再最优（基准下 r=2 的分配 2.846 > 2.827）。

## 快速返回极限 λ→∞

平台上 S' = −(η/N)βcS = −γη/(1−q)，即现有理论取 s̄=0、前因子乘 1/β。

| | 极限解析 Δt / J | λ=1 模拟 Δt / J | λ=1/14 模拟 Δt / J |
|---|---|---|---|
| 西安 仅隔离 | 384.3 / 213.2 | 387.8 / 212.1 | 425.3 / 192.9 |
| 西安 仅减少接触 | 882.9 / 314.7 | 881.1 / 313.6 | 857.2 / 299.5 |
| 基准 仅隔离 | 18.1 / 9.41 | 20.9 / 8.37 | 19.2 / 2.83 |

西安平台期远长于 14 天隔离期，λ=1/14 接近该极限（时长差约 10%）；基准平台期与隔离期相当，极限不准。
