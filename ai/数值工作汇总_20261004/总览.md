## 结果要点

### 1. 同条件四策略比较（01，fig_compare_baseline / fig_compare_xian，results/compare_*.csv）

相同启动状态 S*、相同退出状态 S_c 下比较仅减少接触、显式 α=0.5、仅隔离、类内最小成本。

| | 基准：Δt / 累计感染 / J / (I+I_q)峰值÷η | 西安：Δt / 累计感染 / J / (I+I_q)峰值÷η |
|---|---|---|
| 仅减少接触 | 36.26 d / 628.6 / 11.94 / 1.02 | 308.8 d / 3.86×10⁶ / 109.36 / 1.46 |
| 显式 α=0.5 | 9.24 d / 323.4 / 2.55 / 1.64 | 124.6 d / 2.64×10⁶ / 44.53 / 3.20 |
| 仅隔离 | 5.90 d / 285.7 / 2.22 / 1.92 | 85.1 d / 2.38×10⁶ / 40.77 / 4.73 |
| 类内最小成本 | 7.75 d / 306.6 / 2.12 / 1.89 | 108.8 d / 2.53×10⁶ / 38.02 / 4.73 |

类内最小成本相对仅隔离：基准 J −4.7%、Δt +31%、累计感染 +7.3%、新增 S_q −5.4%；西安 J −6.7%、Δt +28%、累计感染 +6.6%、新增 S_q −2.0%。当前参数下，成本降低的幅度小于时长和感染增加的幅度，可直接支撑"最快、感染最少、最省成本须区分"的主线。

### 2. 成本—时长前沿（01，fig_frontier_*，results/frontier_*.csv）

对 J+κΔt 逐状态最小化并扫描 310 个 κ，得到给定时长下的类内最小成本曲线。Δt 随 κ 连续变化，未见跳跃；显式 α 族除两端点外都在曲线上方。若某个 κ≥0 给出 Δt=T，则该控制就是"Δt≤T"约束下的类内最小成本控制（无需凸性）。

### 3. 能力案例（01，fig_capacity，results/capacity.json）

允许区间非空等价于 (1−u_max)(1−q_cap) ≤ (1−q0)S_c/S*（u_max=1−c_min/c0）。能力平面分为三区：单一控制可行、需要联合分配、到阈值再启动已不可行。代表点：基准 (u_max, q_cap)=(0.5, 0.6)，Δt=8.34 d、J=2.361（比无上限高约 11%）；西安 (0.5, 0.75)，Δt=116.8 d、J=41.62，(I+I_q) 峰值由 4.73η 降到 3.51η。

### 4. 权重敏感性与相图（01，fig_phase_weights，fig_weights，results/phase_weights.json，weights.json）

只有 r=w_q/w_c 影响最优分配。r 较小时（含论文默认 r=2），全局最优分界恰为 s=s_sw（基准 2.265，西安 2.548）：右侧仅隔离、左侧混合。r 超过约 3.24（基准）/2.74（西安）后，仅隔离区向启动端收缩；超过约 13.4（基准）/7.66（西安）后，整个平台期都不用仅隔离。退出处接触份额与 r/(1+r) 吻合。相图可替代 4 条曲线的权重图。

### 5. 结构命题数值核对（01，results/summary.json 的 structure_checks）

r ∈ {0.1, 0.5, 1, 2, 5, 20}，两组参数：仅减少接触端的右导数处处为负（仅减少接触不是最小点）；仅隔离端为局部最小当且仅当 s ≥ s_sw。

### 6. 成本形式稳健性（01，results/linear_cost_xian.json）

线性加权 J_c+2J_q 下：TDINN 69.49、线性最优分配 72.03、仅隔离 73.60、二次最小成本分配 83.29、仅减少接触 173.81。二次成本下阈值类策略低于 TDINN（40.77、38.02 对 49.39），线性成本下反之。仓库 AGENTS.md 规定不以线性综合指标作主要比较，这里只作稳健性检验，是否写入附录由作者决定。

### 7. 隔离易感者返回检验（02）

λ=1/14 时：西安控制时长约变为 5 倍（仅隔离 85→425 d），累计感染三种策略均约 79%N，仅隔离同时隔离峰值约 17%N；时长排序、混合优于仅隔离、S=S_c 退出后无反弹均保持。平台期 S 的减少约 78%–79% 来自进入 S_q 的未感染者（无回流模型，西安）。快速返回极限 λ→∞ 可解析处理（现有理论取 s̄=0、前因子乘 1/β），西安下与 λ=1/14 的时长相差约 10%。

## 注意事项

- 图件为初稿（Noto Sans CJK 字体、未按期刊尺寸），入稿前需按正文样式重绘。
- (I+I_q) 是感染者人数，不是医疗占用；不能直接写成"ICU 需求为几倍"。
- 前沿曲线由 κ 扫描得到的是支撑点；Δt 随 κ 连续是数值观察。
- 能力代表点为演示所选，可按实际能力情景替换。
- 正式采用时，建议把 01 的程序接入 `reproducibility/` 链条，按仓库约定输出未取整结果与验收记录。
