## 2. 成本—时长前沿（fig_frontier_*）

对 J+κΔt 逐状态最小化并扫描 κ（310 个值），得到"给定时长下的类内最小成本"曲线；Δt 随 κ 连续变化，未见跳跃。κ=0 为最小成本点，κ→+∞ 趋于仅隔离，κ→−∞ 趋于仅减少接触。显式 α 族除两端点外均位于该曲线上方。从仅隔离到最小成本的一段 J 下降平缓；超过最小成本后，延长时长换来的是更少的隔离易感者，而非更低成本。扫描只给出支撑点，未证明可达集凸性。

## 4. 权重敏感性（fig_weights）

y = (1−c/c0)/(1−S_c/S) 为接触承担份额，y=0 为仅隔离，y=1 为仅减少接触。

| r=w_q/w_c | 基准 J | 基准 Δt | 西安 J | 西安 Δt | 退出处 y（数值 / 理论 r/(1+r)） |
|---|---|---|---|---|---|
| 0.5 | 0.550 | 6.33 | 10.05 | 89.80 | 0.3332 / 0.3333 |
| 1 | 1.087 | 6.78 | 19.77 | 95.20 | 0.4999 / 0.5 |
| 2 | 2.118 | 7.75 | 38.02 | 108.81 | 0.6666 / 0.6667 |
| 5 | 4.798 | 11.45 | 78.00 | 178.16 | 0.8334 / 0.8333 |

- r ≤ 2：仅隔离区间恰从 s_sw 开始（基准 2.265，西安 2.548），与权重无关。
- r = 5：s ∈ [s_sw, 2.82]（基准）两个局部极小并存，全局最优在 s=2.549 处由内部点跳到仅隔离（西安在 s=3.376）。
- 结构命题数值核对（r ∈ {0.1, 0.5, 1, 2, 5, 20}，两组参数）：仅减少接触端的右导数处处为负；仅隔离端为局部极小当且仅当 s ≥ s_sw。
