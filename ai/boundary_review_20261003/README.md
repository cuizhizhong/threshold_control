```bash
python -m pip install mpmath==1.3.0
python boundary_shift_check.py
```

程序使用 60 位和 90 位工作精度，检查成本、45天、150天三条内部边界，在 `[N_floor, 13163000]` 上取41个人口点，输出123条核查记录。闭式成本原函数另与直接积分比较。输出保留高精度计算值，只用于检查微小的几何差异，并不宣称临床参数或拟合参照具有同样精度。

## 重要判断

1. 精确边界是 `eta(N)=N theta(I0/N)`，不是一条精确的平移直线。平移直线只是一阶近似。
2. `theta(0)` 是正初始感染比例趋于零时，首次积分和阈值控制段公式的连续延拓；不是用 `I0=0` 的ODE生成疫情。
3. 求初值导数时必须同时取 `s0=1-i0`。
4. 当前图件的斜率不是 `theta(0)`，而是在人口 `N_ref=13163000` 下求得的 `theta(I0/N_ref)`。程序分别输出两种参考直线的误差。
5. 工作精度比较和有限采样不构成整个连续人口区间上的区间算术认证；若论文要写严格上界，需要二阶导数的显式界或可靠区间方法。
6. 所有集合归属应用实际 J 与 Delta t 判断，不能以接近四舍五入直线的距离替代。
7. 仓库 `main_critical` 已直接求精确人口交点，原表的显示精度可以保留；不能把同一个精确上界继续无条件定义为峰值除以常数斜率。

## 核查概览

- 成本边界：零初值极限斜率约 0.001654978189117816，一阶人数偏移约 9.560797078177224e-6。
- 45天边界：斜率约 0.003761623581665296，一阶人数偏移约 8.959198037658239e-6。
- 150天边界：斜率约 0.001137089623596784，一阶人数偏移约 2.652579046419752e-6。
- 三条边界的采样最大相对误差（相对于各自零初值极限直线）约为 5.44703330e-7、2.24570109e-7、2.19953961e-7。
- 这些数值与用户提供的数量级相符，但不支持把精确边界称为直线。
- 成本人口交点独立高精度解约 92174.1979634278，仓库保存值为 92174.19796338081；差约 4.70e-8 人，落在原求根设置所允许的尺度内。
