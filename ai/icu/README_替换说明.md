# 完整 TeX 替换文件

## 如何使用

先备份本地文件，再将本包 `latex/` 目录中的以下文件放入原工程的 `latex/`，覆盖同名文件：

- `flatten_curve_analysis_cn.tex`：完整主稿，不是局部片段。
- `flatten_curve_supplement_cn.tex`：完整补充材料。医疗需求推导和阈值量级参考已经从正文移至本文件，原补充表 S1–S3 保留。
- `build_paper.ps1`：使用原一键编译方式时同步替换。补充材料新增了文献引用，脚本增加了对补充材料运行 Biber 的步骤。

原工程的 `references.bib`、`elegantpaper.cls` 和图件目录继续使用现有版本，不需要替换。本包没有增加新的文献条目；Baas 等条目已经存在于当前仓库。

在 Windows PowerShell 中从工程根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\latex\build_paper.ps1
```

也可在 `latex/` 内依次对补充稿执行 XeLaTeX、Biber、XeLaTeX、XeLaTeX，再对主稿执行同一顺序。务必先编译补充稿，使主稿能读取新增的跨文档标签。
