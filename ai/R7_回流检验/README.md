## A 立即返回极限 λ→∞ 可以解析处理

$S_q\equiv0$，$\dot S=-\beta cSI/N$。阈值控制期内 $\dot S=-(\beta\eta/N)c_c(S)S$，即无回流理论中取 $\bar S=0$、前因子 $N/\eta$ 换为 $N/(\beta\eta)$。等价的解释：追踪只把已感染的接触者移出社区（如检测后释放阴性接触者）。

| 结论 | 无回流（λ=0，现稿） | 立即返回（λ→∞） |
|---|---|---|
| 控制时长排序 | 仅隔离 < 混合 < 仅减少接触 | 相同（被积函数 $1/(c_cS)$ 关于 $c_c$ 递减） |
| 控制期累计感染 | $\beta(S^*-S_c)+(1-\beta)\gamma\eta\Delta t$，与 $\Delta t$ 同序 | 恒为 $S^*-S_c$，与控制组合无关 |
| 隔离负担 | 新增 $S_q$：$(1-\beta)[S^*-S_c-\gamma\eta\Delta t]$ | 隔离人次：$\frac{1-\beta}{\beta}[S^*-S_c-\gamma\eta\Delta t]$（数值核对一致） |
| 成本最优控制结构 | 切换点 $S_{\rm sw}\in(2S_c,3S_c)$；退出比例 2/3、1/3 | 切换点 $3S_c$（数值 2.9998）；退出比例 0.667 |
| 退出下界 | $\Itcum\ge\beta(S_0-S_c)$ | $\Itcum\ge S_0-S_c$（西安约 $1.02\times10^7$） |

λ=5 的完整模型模拟与极限一致：西安控制期感染 $1.013\times10^7$（极限 $1.014\times10^7$），各控制的全过程感染都是 $1.064\times10^7$；时长为 385/494/883 d（极限 384/494/883）。

## C 真正的一次性退出

02 目录 `sq_return.py` 中，`oneshot` 标志在控制关闭时不会置位，因此 `oneshot` 实际等同于 `feedback`。本目录按“控制首次关闭后永不重启”重算 λ=1/14，结果与原表完全相同：退出后 $\max I/\eta=1.0000$，不反弹，结束时 $(S+S_q)/S_c$ 为 0.81（基准）与 0.91（西安）。02 目录“退出后无反弹”的结论成立。
