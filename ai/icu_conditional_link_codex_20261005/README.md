# 社区感染阈值与医疗容量的条件性联系：Codex局部修改包

## 这是什么

这是“已经写好的论文替换段落＋局部整合计划”，不是另一份整篇论文，也不是已完成临床校准的数值发布包。

本轮定位固定为：以避免医疗需求过载为现实动机，以社区非隔离感染峰值为直接控制对象；通过全部新增感染流量给出与医疗容量的条件性联系；在给定、可实施的社区感染阈值下，研究规定三阶段策略的解析结构和双控制分配。

本包不加H、不改传播方程和原理论、不增加线性成本或回流分析、不新增医疗需求图、不重算西安。θ=0.002及已有联合控制结果保留为设计情景。临床校准留作单独批准的后续工作，不阻塞本轮局部合并。

## 交给Codex的入口

先阅读 `CODEX_执行计划.md`，然后按 `merge_manifest.json` 将 `tex/` 内八个块局部合入当前本地活动稿；`anchors/` 提供读取时的原段落，仅用于定位和检查，不能恢复旧版本整稿。最后将 `bibliography/Baas2021Occupancy.bib` 中唯一新条目合并入当前参考文献库。
