## v2 相对 v1 的修正

| 审阅意见 | 核实结果 | v2 的处理 |
|---|---|---|
| `capacity_structure` 把受限启动时的接触率当成 $c_0$ | 属实。受限分配启动时 $c\approx0.609c_0$，v1 的“无限制分配接触减少 ≤ 能力上限”检查因此失效。反例测试：把 $u_{\max}$ 改成 0.15，v1 不报错，v2 报错。正文数字未受影响（启动降幅由平衡式 $1-s_{\rm cap}/s^*$ 计算） | $c_0$ 从 `input_manifest.json` 读取，并与任务 B 诊断的 `c_max` 交叉核对；`allocation_structure` 同样改为从参数读取 $c_0$ |
| 7.2：“前段仅隔离”不是由命题 6.12 推出 | 属实。命题只给出 $S<S_{\rm sw}$ 时两种措施同时使用，以及 $S>S_{\rm sw}$ 时仅隔离是局部最小点 | 分开写：前者由命题保证；$S>S_{\rm sw}$ 上取仅隔离、切换在 $S_{\rm sw}$ 且连续，是 $w_c=1,w_q=2$ 下比较全部候选的数值结果，并绑定任务 A 的切换记录 |
| 7.2：7.62 d 指谁 | 属实，原句有歧义 | 改为“仅隔离与最低成本分配的这一峰值都出现在启动后约 7.62 d”；生成器同时核对两者的峰值时刻相同 |
| 7.3：“两种分配一致”的含义 | 属实。一致的只是同一 $S$ 处的 $c_c(S),q_c(S)$；受限分配到达同一 $S$ 的时刻较晚，$I_q,S_q$ 也不同 | 正文写明“只指同一易感者状态下的控制，并非相同时刻的完整轨迹相同” |
| 7.3：分段时刻用已有诊断 | 属实。任务 A、B 的 `time_diagnostics.nominal_segment_methods` 记有各段起止时刻和 $S$ 边界 | 1.94、0.26、30.38、1.61、25.46 d 都改从诊断读取（与 v1 插值结果在报告精度内相同）；接触率最大降幅改用诊断 `c_min`。轨迹 CSV 只用于核查，不再作为数字来源 |
| 7.4：保持有限网格表述；$r=2$ 不是网格点 | 属实。$r=2$ 位于网格点 1.969 与 2.036 之间 | 改为“网格点 $r\le3.13$ 的各点”“相邻网格点 3.24 起”“出现仅隔离段的最大网格点 13.00 / 7.41，从 13.44 / 7.66 起不再出现”，并注明精确转折位于相邻网格点之间、未求解；$r=2$ 的结论改为引用任务 A 在 $r=2$ 下的单独候选比较 |
| 7.5：保留“充分条件” | 属实。v1 的句子本身没错，但删掉了“充分”二字 | 写回“注记 6.13 给出的是充分条件”，并补一句“计算点之间的时长上的最低成本未由此确定” |
| 7.5：11.09 d 不是临界值 | 属实 | 改为“满足 $J\le1.10J_{\min}$ 的计算点中最大时长约 11.09 d，下一个计算点（11.40 d）约为 $1.12J_{\min}$；11.09 d 不是精确临界时长” |

另一处顺带收紧：7.5 中“缩短到仅隔离 $J$ 至多 +5%”改写为严格陈述——要求 $\Delta t\le T$（$5.90\le T\le7.75$ d）时仅隔离可行，所以类内最小成本介于 $J_{\min}$ 与 $1.05J_{\min}$ 之间。这一结论不依赖计算点。

## 生成器读取的数据与检查

- 数字来源：`input_manifest.json`（$c_0$）、`validation.json` 任务 A/B 的 `time_diagnostics` 与 `candidate_checks.switches`、`compare_*.csv`、`capacity.json`、`phase.json`、`phase_*.npz`、`frontier_baseline.csv`。
- 结构性陈述各设检查，输出变化使陈述不成立时直接报错：
  - $S^*>S_{\rm cap}>S_{\rm sw}$；
  - 默认权重下切换点唯一、连续且位于 $S_{\rm sw}$（任务 A、B 各自核对）；
  - 最低成本分配在 $S>S_{\rm sw}$ 上 $c=c_0$；
  - 受限启动降幅与平衡式一致；
  - 无限制分配的接触减少不超过能力上限；
  - 同一 $S$ 处受限与无限制控制一致；
  - 相图切换边界“先连续、后跳变”，$r=2$ 不是网格点且位于连续段内；
  - $\kappa\ge0$ 计算点成本不高于仅隔离；
  - $\kappa<0$ 计算点在 $J$ 与 $\Delta t$ 上都劣于最低成本点。
