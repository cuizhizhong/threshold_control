## 控制律与逐状态最小化

允许区间 x ∈ [1/z, 1]（不考虑能力约束）。成本最优控制在每个 z 上最小化 S 坐标下的成本密度：

- 无回流：φ0(x) = [w_c(1−x)² + w_q(1−1/(xz))²]/(xz − z̄)；φ0′ 的分子由 SymPy 导出，是 x 的五次多项式，分母 x³z²(xz − z̄)² 在允许区间上为正。
- 立即返回：φI(x) = [w_c(1−x)² + w_q(1−1/(xz))²]/(xz)；x⁴h_a′(x) = w_c x⁴ − (w_c+w_q)x² + 4a w_q x − 3a² w_q，a = 1/z。测试核对五次式在 z̄ = 0 处等于 z³·x·(四次式)。

numpy.roots 求全部根。候选集为两个端点，加上虚部不超过 1e-4·max(1,|根|) 的根的实部，条件是它落在区间内（区间外 1e-12 以内的截到端点）。候选都是可行点，逐一比较 φ 值，所以多收的近似实根只会增加候选，不会使结果变差。严格实根（虚部 ≤ 1e-10·max(1,|根|)）另计，仅作诊断。相距小于 1e-12 的候选合并（近似重根）。值在 min + 1e-15·max(1,|min|) 以内的候选算并列，取 x 最大者（更接近仅隔离），并记录并列个数。

两种网格分开：N_x 是固定 z 时对 x 的等距网格，只用于核对根法；N_z 是 S 坐标求积与切换位置定位的网格（默认 4001）。切换位置的求法：

- 最优点类型（端点或内部）改变、且 x 连续时，对“驻点多项式在该端点的值”用 brentq 求根；
- x 间断时，用二分法加密；
- 陡峭但连续处（x(z) 导数无界）只作求积分段点，并在该端用分级网格 z = 端点 ± L·u³ 去掉立方根奇性。

求积主结果为分段 Simpson；另以 `scipy.integrate.quad`（epsrel 1e-12，同样分段）交叉核对。

无回流最优律迁移：其他 ω 下在任何所需的 z 上（包括超过无回流 S* 的状态）直接按 ω = 0 的逐状态最小化计算 x(z)，不插值、不外推。

## 状态与事件设计（`simulate.py`）

状态向量 y = [s_N, ln i_N, sq_N, iq_N, r_N, cinf_N, J, kq_N]，各阶段相同，阶段之间连续衔接。cinf_N = ∫F dt/N（累计新增感染）、J、kq_N = ∫A_q dt/N（未感染接触者累计追踪人次；ω = 0 时即新增隔离易感者）各为独立积分的状态，不由 U(0) − U 定义。感染者用 ln I 表示，保证正性与相对精度（西安 i0 ≈ 7.65e-11）。

| 阶段 | 控制 | 事件 |
|---|---|---|
| 常规 | (c0, q0) | 触发：ln i − ln θ = 0，方向向上，终止。ω = 0 与立即返回时另设 S 由上方到达 S_c（未触发，此后 I 单调下降），终止。I0 > η：退化分支，不积分；I0 = η：S0 > S_c 时 t1 = 0 |
| 阈值弧 | c = c0·x(S/S_c)，q = 1 − γN/(βcS) | I ≡ η 由代数给出（ln i 取 ln θ，导数为 0，触发事件处的偏差作为事件残差报告），其余状态照常推进；退出：s_N − s_c = 0，方向向下，终止 |
| 退出后 | 永久 (c0, q0)；可选在 t2 释放 ξS_q | 见下 |

退出后的终止按模型分支：

- **ω = 0 与立即返回**：清零事件 I = 1 只在退出之后、方向向下时触发（基准 I0 = 1，常规阶段不设此事件）。t→∞ 的值按首次积分 I + κ(S − S_c ln S) = 常数解析补尾（ω = 0 时 κ = β(1−q0)/(β+(1−β)q0)，即定理 3.5 的 S_∞；Lambert W 主支与 brentq 交叉核对）。在 t2 释放时，ω = 0 下 S 单调下降、I 单峰，首次 I < 1 已在释放引起的波之后，再解析补尾。
- **ω > 0**：U < S_c 后用尾部误差上界 B(T) = βc0U(T)I(T)/(Nγ[1 − U(T)/S_c])。积分到 B ≤ ε_tail（默认 1e-6·U(0)，基准 7.62e-4 人、西安 13.16 人）为止，用事件 ε_tail·γ(1 − U/S_c) − βc0UI/N = 0（方向向上）实现。输出“最终规模估计 = 终止时累计感染 + [0, B]”。到积分上限（默认 1e5 d）仍未满足的，记为 `not_reached`，标记最终规模未可靠估计。I < 1 不当作尾部感染为零。

退出后峰值：İ = 0 用两个非终止事件定位，事件函数为 İ/I = βc0(1−q0)s − γ，由正变负为极大、由负变正为极小。内部极大与端点 t2（I = η）、终止时刻比较，得到未取整的 e = max I/η − 1。t2 处本来就有 İ = 0；紧邻 t2（t − t2 ≤ 1e-9·(1+t2)）的伪事件剔除，个数记为 `n_guarded_events`。判据为绝对判据，容限 e_tol = 1e-8：

- e_interior 或 e_end > e_tol：`crossed`；
- 两者都 < −e_tol（或没有内部极大）：`not_crossed`；
- 其余：`undetermined`（数值上未确定）。

“I 降到 1 以下后再回升”另记：`below_one_time`（首次向下穿越 1）、`regrowth_after_below_one`（此后出现 I 的极小）、`regrowth_peak_I`、`recrossed_one`。另记首次 I < 1 时的累计感染 `C_below_one`，它是旧实现的终止口径，只作对照。

## 已知事项

- 立即返回对照模型、默认权重下，成本最优控制律 x(z) 在 z = 2√2 处有立方根型的陡峭点：驻点四次式在 x = 1/√2 有三重根。x(z) 连续，不是切换点；全局最优在 1 < z < 3 内部取得，在 z = 3 连续切换到仅隔离。求积在该点分段并用分级网格。
- 无回流、默认权重下，根法给出的全局切换位置与 S_sw/S_c = (3 + √(9 − 8z̄))/2 一致到 1e-15（基准 2.265368799991，西安 2.548250542571）。
