## 自动检查的边界与人工复核

不能将自动检查结果一概表述为“全部无警告”：

- 通用 Nature 静态预检要求显式无衬线字体，因此 `FONT-FAMILY` 仍报 FAIL。本项目用户明确要求保留原图字体；本轮遵守原脚本的 Times/STIX，**不为满足默认检查而换字体**。这是任务约束覆盖默认规范，并非缺失字体。该预检还对非 89/183 mm 宽度、仅 PNG 预览和 300 dpi 提示 WARN；本稿按现有版心排版，实际嵌入的是矢量 PDF，不声称完成某个指定期刊的投稿预检。
- 原始 PDF 碰撞报告保留在 `qa/*.collision.json`。部分 FAIL 来自未应用坐标区裁剪的路径，或把多个字符合成一个包围框后的空白区域相交。`qa/collision_geometry_review.json` 按实际裁剪区和单字形重新检查，排除了这些误报。
- 数学标记 `I_peak^T` 的三个 text-text 报告已通过放大裁切图 `review_013.png`、`review_032.png`、`review_033.png` 复核：上下标无重叠，属于数学文字组合的包围框误报。
- 内嵌柱形图背景和柱顶数值边界的 WARN 已结合整图及最终页面查看：内嵌白底为原设计，数值可读；没有为避开检查而删除科学元素。
- 本次依据 nature-figure 的最终尺寸/字形/对齐检查，以及 nature-polishing 和 PDF 的渲染复核流程；用户指定的原图样式优先于技能的默认字体、宽度和期刊风格。
